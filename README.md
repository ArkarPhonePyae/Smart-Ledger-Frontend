# Smart-Ledger-Frontend

Frontend repository for Smart Ledger / AuraPay application.

## AuraPay — Angular 20 Conversion

This is a pixel-faithful Angular 20 (standalone components) conversion of the original single-file `index2.html` prototype ("AuraPay — Modern Fintech Expense Settler Platform"). Every visible section, class, animation, and interaction from the original has been preserved; nothing has been redesigned.

## Getting started

```bash
npm install
npm start        # ng serve, http://localhost:4200
npm run build    # production build to dist/aurapay-angular
